# 煎煮中药的 10 个关键细节：做对药效翻倍

> 更新时间：2026-09-17 (UTC+8)

点击箭头处“蓝色字”，关注我们哦！！

中药煎煮有讲究，10 个细节帮你煮出好药效 ！

**一、选对锅具：避开金属，优选砂锅**

✓ 禁用铁锅、铝锅、铜锅(易与药物反应)。

✓ 推荐砂锅、不锈钢锅、陶瓷 / 玻璃锅(性质稳定)。

**二、泡药加水：水量随药调整，浸泡水别丢**

✓ 普通药加水没过药面 2-3cm。

✓ 草叶花类多加水，坚硬根茎类少加水。

✓ 所有药材浸泡 30 分钟，泡药水直接煎煮。

**三、煎煮次数与火候：两煎合并更高效**

第一煎：大火煮沸转小火煮 30 分钟。

第二煎：药渣加水 1-2cm，小火煮 20 分钟。

两次药汁合并，成人每次 200-300ml。

**四、先煎药：硬药先煮，释放药效**

✓ 适用：矿物贝壳类(龙骨、牡蛎)、有毒药(淡附片)、动物甲类(穿山甲)。

✓ 操作：先煎 15-30 分钟(有毒药先煎 1-2 小时)，再入其他药同煎。

**五、后下药：娇气药后放，保留活性**

✓ 适用：芳香类(薄荷、砂仁)、泻下类(大黄)、易挥发类(钩藤)。

✓ 操作：第一煎结束前 5-10 分钟加入，煮至完成。

**六、胶类药：融化冲服，避免焦糊**

✓ 如阿胶、鹿角胶：粉碎后用滚水冲泡融化，倒入药汁服用

✓ 忌直接入锅煮，易黏锅浪费药效。

**七、粉末药：直接冲服，保留成分**

✓ 如三七粉、羚羊角粉：用温水或药汁冲服，或搅拌成糊状。

**八、药引搭配：姜枣用量有标准**

✓ 生姜：3片(1 元硬币大小厚度)。

✓ 红枣：3-5 颗(中等大小，掰开去核)，与药同煎。

**九、服药时间：按药效选时机**

✓ 饭后服：消食药、胃肠刺激药。

✓ 空腹服：通便药。

✓ 睡前服：安神药。

**十、忌口与储存：细节决定效果**

❌ 忌口：烟酒、辛辣、油腻、生冷。

✓ 储存：未煎药放阴凉干燥处，煎好药汁冷藏(≤48 小时)，喝前温热。
